Cookie Overview

This site uses a compact local-storage notice so the browsing experience stays clean and unobtrusive. The notice lets visitors acknowledge the policy once instead of seeing the same message on every page.

At this time, the website's consent mechanism uses browser local storage rather than a traditional tracking cookie. Browser vendors may group local storage, cookies, and site data together inside their privacy settings.

Stored Data

When you accept the cookie notice, your browser stores a local value named timberrootCookieConsent. It records that the notice was accepted on this device and browser.

  • The value is stored locally in your browser.
  • It does not include your name, email address, selected service, project message, or photos.
  • It may not carry across browsers, devices, private browsing sessions, or cleared site data.

Storage Purpose

The value prevents the sticky notice from reappearing on every page. It helps keep the interface focused while still giving visitors access to the cookie policy and privacy policy.

We may also use normal technical data that web hosting, security, and browser systems need to load pages, prevent abuse, measure site reliability, and diagnose errors. This technical data is separate from the local consent value.

Forms

Contact form details are separate from the cookie notice. Form submissions are used to respond to your inquiry and should not include sensitive information.

If a form includes optional project details, those details are provided by you voluntarily. Please include only information needed to describe the tree, stump, access conditions, cleanup needs, or timing preferences for the inquiry.

Manage Storage

You can clear local storage or site data in your browser settings. If cleared, the compact notice may appear again because the browser no longer has the saved acceptance value.

Most browsers let you manage site data from privacy or security settings. Some browsers also provide controls for blocking third-party cookies, deleting data on exit, or using private windows that discard local values after the session.

Policy Changes

If the website later adds analytics, advertising, embedded tools, maps, chat widgets, or other third-party services that rely on cookies or similar technologies, this policy should be updated to describe those tools and available choices.

When this page changes, the updated date above will be revised. Continued use of the site after a change means the current version applies to your visit.
